Sobre nosotros

Una plataforma diseñada
para la comunidad IDEP

El Sistema Académico IDEP nació como proyecto del equipo de Frontend 1 para centralizar la gestión académica del colegio. Permite a estudiantes consultar su rendimiento y a administradores gestionar la información de forma ágil.

Desarrollado con HTML, CSS y JavaScript puro, sin frameworks externos.
